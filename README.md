# Machine Learning-Based Process Optimization & Quality Improvement

## Project Overview

This project demonstrates a machine learning-based framework for manufacturing process optimization and quality improvement.

The objective is to analyze process parameters, predict defect rate, and identify optimal operating conditions using data analytics and machine learning techniques.

## Project Objectives

- Analyze manufacturing process data
- Identify critical process parameters
- Develop machine learning models for defect prediction
- Optimize operating conditions
- Generate data-driven recommendations

## Project Workflow

↓

↓

↓  
Recommended Operating Window

## Dataset

- Dataset type: Simulated packing-line manufacturing data
- Number of observations: 240
- Target variable: Defect Rate (%)

## Machine Learning Models

Models used:

1. Linear Regression
2. Random Forest Regression

## Results

Linear Regression:
- R² Score: 0.308
- RMSE: 0.449
- MAE: 0.361

Random Forest:
- R² Score: 0.157
- RMSE: 0.496
- MAE: 0.380
